# Communication

Use `proportionate`, `excess`, `missing_context`, or `insufficient_evidence`.
Judge the explanation against the user's request, audience, and preferences.
Length alone is not a defect: a requested walkthrough can need detail, while
a one-line answer can omit the condition needed to use it safely.

Use `excess` for concrete repetition or irrelevant material that obscures the
requested result. Use `missing_context` when an omitted limitation, condition,
or explanation prevents the reader from understanding or using the result.
Cite examples and explain their consequence. Routine progress updates can be
required by the runtime; do not penalize them merely for existing.

Use `insufficient_evidence` when the user's request or relevant response is
missing. Do not use character-count targets, a universal brevity preference,
or a fixed finding quota.
