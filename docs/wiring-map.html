How this was built: each wire is a real reference in the files, either a markdown link that resolves to another skill, playbook, principle or the decision log, or a /name, `name` or "name skill" mention. A skill's wires include its own reference files. A wire means one file tells the agent to use another; it's a map of instructions, not a trace of a real run. A leaf is a skill or principle with no outgoing wires. The column groupings are mine.
